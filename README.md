# A Arquitetura do Caos

Livro original em desenvolvimento, em português brasileiro.

**Proposta:** ensinar arquitetura de software, system design e pensamento sistêmico por meio de uma história envolvente, narrada por NORA, uma inteligência artificial sarcástica.

**Extensão-alvo:** aproximadamente 90–110 páginas, sem preenchimento artificial.

## Política de preservação

1. O texto aprovado é a referência; revisões devem ser explícitas e versionadas.
2. Antes de modificar um capítulo, consultar a Bíblia, o sumário, os personagens e o texto já escrito.
3. Cada mudança deve preservar o histórico do Git e ter um commit descritivo.
4. Não tratar conteúdo inventado como fato histórico ou técnico; verificar informações factuais.
5. O repositório é público por escolha do autor. A publicação aqui não implica que o manuscrito esteja finalizado.
